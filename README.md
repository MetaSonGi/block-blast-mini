# 블록 블라스트 미니

2026년 대세 **Block 메카닉** 퍼즐 게임.
8×8 보드에 블록을 놓고 가로·세로 한 줄을 채워 터뜨리자!

🌐 **바로 실행:** https://metasongi.github.io/block-blast-mini/

## 게임 방법

1. 아래 트레이에서 블록을 터치해 선택
2. 보드의 빈 칸을 터치해 배치 (미리보기 표시)
3. 가로 또는 세로 한 줄이 가득 차면 폭발! (여러 줄 동시 = 점수 제곱 보너스)
4. 놓을 곳이 없으면 게임 오버 — 최고 기록에 도전

## 기술

- Vanilla JS + CSS Grid
- 배치 가능 여부 실시간 검사, 고스트 미리보기
- 최고 기록 localStorage 저장
- 모바일 터치 대응
